Engineering browser-based research tools with EasyEyes

My contributions to experiment compilation, clearer diagnostics, and maintainable software.

By Mohammadreza “Reza” Khahani · Senior Software Engineer

The project

EasyEyes is an open-source platform for running vision research experiments in the browser. Its repositories cover the public website, experiment compilation, experiment execution, and remote calibration. This work brings software engineering into a research workflow where experiment setup and clear feedback matter.

My contribution

I contribute across the EasyEyes website, experiment compiler, and threshold experiment workflows. My work includes making compiler diagnostics and Glossary audit warnings clearer and more actionable, strengthening automated testing, and maintaining dependency security across the repositories, including remote-calibrator.

Helping researchers understand compiler feedback

Experiment compilation needs to communicate issues in a way an experimenter can act on. My contributions focus on clearer diagnostics and Glossary audit warnings, alongside improvements to compilation and validation workflows.

Working across the platform

The platform spans several connected repositories. I work with JavaScript, TypeScript, browser-based applications, and automated tests to investigate behavior and verify changes. I also use AI coding agents for codebase investigation, implementation, testing, and review, with human oversight of technical decisions and releases.

Explore the code

  • Website — the public EasyEyes website.
  • Threshold Scientist — the experimenter-facing application that generates experiment files in the browser.
  • Threshold — a PsychoJS-based experiment generator for measuring psychometric thresholds.
  • Remote Calibrator — tools for screen-size measurement, viewing distance, and gaze.
